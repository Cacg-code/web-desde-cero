Chuletas por curso

Cada chuleta se desbloquea al completar las 11 lecciones de su curso. Es un incentivo de motivación: tu progreso se guarda solo en tu navegador, así que no es una acreditación. Puedes imprimirla o guardarla como PDF.

🧱 HTML

<!doctype html>
Declara que es HTML5; va siempre primero.
<html lang="es">
Idioma de la página (lectores de pantalla y SEO).
<meta name="viewport">
Imprescindible para que sea responsiva en el móvil.
<h1>…<h6>
Títulos. Un solo h1 por página y sin saltar niveles.
<a href>
Enlace. Usa rel="noopener" con target="_blank".
<img src alt>
Imagen; alt describe lo que se ve (vacío si es decorativa).
<ul> · <ol> · <li>
Listas sin orden, ordenadas e ítems.
<table> <th scope>
Tablas solo para datos; thead, tbody y caption.
<label for> + <input id>
Etiqueta enlazada a su campo del formulario.
<header> <nav> <main> <footer>
Semántica: da significado y mejora la accesibilidad.
<title> + description
Lo que se ve en Google: título y resumen.
git add · commit · push
Preparar, guardar y subir tus cambios.

🎨 CSS

.clase · #id · etiqueta
Selectores básicos; la clase es el más usado.
:hover · :focus · ::before
Pseudoclases y pseudoelementos.
margin · border · padding
Modelo de caja; usa box-sizing: border-box.
rem · em · % · vw
Unidades relativas para diseños flexibles.
var(--color)
Variables CSS declaradas en :root.
display: flex
justify-content (eje principal), align-items (cruzado), gap.
display: grid
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)).
position: relative / absolute / sticky
El hijo absoluto se ubica respecto al padre relativo.
@media (max-width: 600px)
Reglas solo para pantallas pequeñas.
transition · animation
Movimiento; respeta prefers-reduced-motion.

⚙️ JavaScript

const · let
Variables. Evita var; usa const por defecto.
=== · !==
Comparan valor y tipo.
`Hola ${nombre}`
Plantillas de texto.
(a, b) => a + b
Función flecha.
if · else · switch
Condicionales.
arr.map · filter · find · reduce
Transforman arrays sin mutar el original.
{ a, b } = obj
Desestructuración.
document.querySelector
Selecciona un elemento del DOM.
el.addEventListener('click', fn)
Reacciona a eventos.
fetch(url).then(r => r.json())
Pide datos; con async/await y try/catch.
JSON.parse · JSON.stringify
Texto ↔ objeto.

⚛️ React

function Tarjeta({ titulo })
Componente: función con mayúscula que devuelve JSX.
<Tarjeta titulo="Hola" />
Props: datos de padre a hijo (solo lectura).
{expresion}
Inserta JavaScript dentro del JSX.
className · htmlFor
Nombres JSX de class y for.
const [n, setN] = useState(0)
Estado; cambia con setN, nunca directo.
useEffect(fn, [deps])
Efectos secundarios; limpia con return.
lista.map(x => <li key={x.id}>)
Listas con key estable.
useContext · useReducer
Estado compartido y lógica compleja.
npm create vite@latest
Proyecto real con Vite.
