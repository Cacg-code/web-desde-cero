Ejercicio: Qué es una base de datos

  • ⏱ 20 minutos
  • 📶 Nivel: principiante

Objetivo

Preparar SQLite, cargar la tabla productos y reconocer en ella tablas, filas, columnas y clave primaria.

Cómo se trabaja

Trabaja en una terminal con sqlite3 (lección 1, apartado «Prepara tu entorno»). No hace falta escribir código complejo: se trata de explorar y de reconocer las piezas de una tabla.

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

💡 Pista 1: si no funciona .read

Abre sqlite3 en la misma carpeta donde guardaste tienda.sql, o escribe la ruta completa del archivo.

💡 Pista 2: qué ver en .schema

Muestra la instrucción CREATE TABLE con el tipo de cada columna. Busca PRIMARY KEY.

✅ Ver una solución posible

Intenta resolverlo antes de mirar. Tu versión puede ser distinta y también correcta.

Resultados esperados y respuestas:

  • Filas y columnas: 8 filas y 5 columnas (id, nombre, categoria, precio, stock).
  • Clave primaria: id.
  • Números: id, precio y stock. Texto: nombre y categoria.
  • (a) Relacional: datos relacionados (clientes, pedidos, productos) que deben ser siempre correctos.
  • (b) NoSQL clave-valor (por ejemplo Redis): son datos temporales y se leen por una clave.
  • (c) Documentos (NoSQL) puede encajar bien por la estructura variable, aunque muchos equipos también lo resuelven con una base relacional.
Terminal · sesión de ejemplo
$ sqlite3 tienda.db
sqlite> .read tienda.sql
sqlite> .headers on
sqlite> .mode column
sqlite> SELECT * FROM productos;
id  nombre       categoria    precio  stock
--  -----------  -----------  ------  -----
1   Teclado      Periféricos  120     15
...
sqlite> .tables
productos
sqlite> .quit

💡 🏁 Reto extra (opcional)

Crea en papel el esquema de una tabla clientes (nombre de cada columna y su tipo) y decide cuál sería su clave primaria.
