Ejercicio: Qué es Node.js y tu primer script

  • ⏱ 30 minutos
  • 📶 Nivel: principiante

Objetivo

Instalar y probar Node en tu computadora y escribir cinco funciones de JavaScript puro que usarás después en scripts reales: un saludo, un resumen de números, un contador de palabras y dos funciones para leer versiones de Node.

Cómo se trabaja

Este ejercicio tiene dos partes. La parte A la haces en tu computadora, con una lista de verificación. La parte B son funciones de JavaScript puro: las pruebas en el editor de abajo (que corre en el navegador) y las compruebas pegando el código en el comprobador.

En el comprobador pega solo las funciones, sin las etiquetas <script>.

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

💡 Pista 1: los textos exactos

saludar("Ana") debe devolver exactamente ¡Hola, Ana! Bienvenido a Node.js, con los signos de apertura y la coma.

💡 Pista 2: resumir

Devuelve un objeto con tres propiedades: min, max y promedio. El promedio es la suma entre la cantidad de elementos.

💡 Pista 3: leerVersion

"v24.11.0".slice(1) da "24.11.0". Luego .split(".") da un array de tres textos y .map(Number) los convierte en números.

🔎 Comprueba tu trabajo

Pega tu código y pulsa Comprobar. La revisión ocurre en tu navegador; nada se envía a ningún sitio. Cada punto en rojo incluye una pista. Pega solo el JavaScript, sin las etiquetas <script>.

    ✅ Ver una solución posible

    Intenta resolverlo antes de mirar. Tu versión puede ser distinta y también correcta.

    soluciones.js
    function saludar(nombre) {
  return `¡Hola, ${nombre}! Bienvenido a Node.js`;
}

function resumir(numeros) {
  if (numeros.length === 0) return null;
  const total = numeros.reduce((suma, n) => suma + n, 0);
  return {
    min: Math.min(...numeros),
    max: Math.max(...numeros),
    promedio: total / numeros.length
  };
}

function contarPalabras(texto) {
  const limpio = texto.trim();
  if (limpio === "") return 0;
  return limpio.split(/\s+/).length;
}

function leerVersion(texto) {
  const [mayor, menor, parche] = texto.slice(1).split(".").map(Number);
  return { mayor, menor, parche };
}

function esSuficiente(texto, minimo) {
  return leerVersion(texto).mayor >= minimo;
}

    💡 🏁 Reto extra (opcional)

    Escribe un script version.js que, con process.version y tu función esSuficiente, imprima «Tu Node es suficiente» o «Actualiza Node». Pruébalo en tu terminal con node version.js.
