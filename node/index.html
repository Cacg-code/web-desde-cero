Node.js y APIs: lleva tu JavaScript al servidor

Aprende a ejecutar JavaScript fuera del navegador y a crear tus propios servidores y APIs con Express: rutas, JSON, middleware, archivos y despliegue. Cada lección combina apuntes, ejemplos con su salida esperada, un editor en vivo para el JavaScript puro y ejercicios para practicar en tu computadora.

Antes de empezar
  • Saber JavaScript (funciones, arrays, objetos y async/await): haz antes el curso de JavaScript.
  • Manejar lo básico de una terminal (moverte entre carpetas y ejecutar comandos).
  • Tener instalado Node.js (la lección 1 te guía) y un editor de código.

      
Lo que construirás
  • Scripts de Node que leen y escriben archivos.
  • Proyectos con npm, scripts y dependencias.
  • Un servidor con Express con rutas y middleware.
  • Una API REST completa que habla JSON.
