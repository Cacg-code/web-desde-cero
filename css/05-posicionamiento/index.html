1.El flujo normal y por qué a veces hay que salirse

Por defecto, los elementos se colocan uno tras otro, de arriba abajo (los de bloque) y de izquierda a derecha (los de línea). Es el flujo normal y casi siempre es lo que quieres.

La propiedad position permite sacar un elemento del flujo o ajustarlo, para casos concretos: una insignia sobre una foto, un menú que se queda arriba al desplazarte, un cuadro de diálogo sobre toda la página. No sirve para maquetar columnas: para eso están Flexbox y Grid (lecciones 6 y 7).

ValorOcupa lugar en el flujoSe coloca respecto a…Para qué
staticSí(valor por defecto, ignora top/left…)Normal
relativeSí (su hueco se conserva)Su propia posición originalAjustes mínimos y referencia para hijos absolute

2.relative: ajustar y servir de referencia

position: relative casi no cambia nada visible por sí solo. Su verdadero valor es otro: convierte al elemento en la referencia de los hijos con position: absolute.

El patrón más usado de posicionamiento
.tarjeta { position: relative; }          /* la referencia */
.insignia {
  position: absolute;                     /* sale del flujo */
  top: 12px;                              /* a 12px del borde superior de .tarjeta */
  right: 12px;                            /* y a 12px del derecho */
}
✏️ Insignia sobre una tarjeta

⚠️ Importante · Sin referencia, se va a otro sitio

Un hijo absolute busca su ancestro posicionado más cercano (cualquier ancestro con position distinto de static). Si no encuentra ninguno, se coloca respecto a toda la página. Por eso casi siempre pones position: relative en el padre.

3.absolute: colocar con precisión

Con top, right, bottom, left (o el atajo inset) indicas la distancia a los bordes de la referencia. Algunos usos habituales:

Centrar un elemento dentro de su padre
.padre { position: relative; }
.hijo {
  position: absolute;
  inset: 0;                 /* top, right, bottom y left: 0 → llena el padre */
  margin: auto;             /* con ancho y alto definidos, queda centrado */
  width: 120px; height: 60px;
}

/* La otra manera clásica */
.hijo2 {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}
✏️ Centrado absoluto

📌 Nota · Hoy hay mejores opciones para centrar

Para centrar contenido normal, Flexbox y Grid son más sencillos (display: grid; place-items: center). absolute se reserva para elementos que flotan sobre otros.

4.fixed y sticky

Aspectofixedsticky
ReferenciaLa ventanaSu contenedor (padre) al desplazar
Ocupa espacioNo (hay que dejar hueco)Sí (conserva su sitio)
ComportamientoSiempre en la misma posición de la pantallaFluye normal hasta alcanzar top: … y entonces se pega
TípicoBotón de WhatsApp, banner de cookiesEncabezado de sección, cabecera de tabla, índice lateral
Barra fija vs encabezado pegajoso
.boton-flotante { position: fixed; right: 16px; bottom: 16px; }

.encabezado {
  position: sticky;
  top: 0;                    /* se pega al borde superior al desplazar */
  background: #fff;
  z-index: 10;
}

⚠️ Importante · Por qué mi sticky no se pega

Las causas habituales: falta top (o bottom/left…), o algún ancestro tiene overflow: hidden/auto, que cambia la referencia del desplazamiento. Revisa la cadena de padres.

5.z-index y apilamiento

Los elementos posicionados pueden superponerse. z-index decide quién queda encima: un número mayor se ve por delante. Solo funciona en elementos con position distinto de static (y en ítems de flex/grid).

✏️ Apilar tres tarjetas

Contextos de apilamiento: la trampa del z-index

Cada elemento con ciertas propiedades (position + z-index, opacity < 1, transform, filter…) crea un contexto de apilamiento: un «mundo aparte» donde los z-index de dentro no compiten con los de fuera. Por eso a veces un z-index: 9999 no logra pasar por encima de otro elemento.

  • Un hijo nunca puede salir por encima de lo que está por encima de su contexto de apilamiento.
  • Usa valores pequeños y ordenados (1, 10, 100) y nómbralos con variables: --z-menu: 10; --z-modal: 100;.
  • Si no logras superponer algo, busca un ancestro con transform, opacity o position + z-index que cree un contexto.

7.float: una pieza de historia

float hacía que un elemento se desplazara a un lado y el texto lo rodeara, como en una revista. Hoy se usa solo para eso: imágenes con texto alrededor. Para maquetar se usa Flexbox o Grid.

Texto alrededor de una imagen
.foto-lateral { float: left; margin: 0 16px 8px 0; width: 160px; }
.despues { clear: both; }      /* el siguiente bloque ya no rodea la imagen */

📌 Nota · Verás float en código antiguo

Hasta hace unos años casi todos los diseños se hacían con float. Si ves código con clearfix, columnas con float: left, etc., es de esa época: puedes sustituirlo por Flexbox o Grid.

8.Errores frecuentes

  • Usar position: absolute para todo el diseño: se rompe en cuanto cambia el tamaño de pantalla o el contenido.
  • Olvidar position: relative en el padre: la insignia se coloca respecto a la página.
  • z-index sin position: no hace nada (salvo en flex/grid).
  • Subir el z-index a 99999: no resuelve un contexto de apilamiento.
  • sticky sin top o con un ancestro con overflow.
  • Un elemento fixed tapa el contenido: deja espacio con padding en el body.
  • Colocar con top/left en px en tamaños críticos: usa %, inset o unidades relativas.

📒 Apuntes para llevar

  • position saca elementos del flujo para casos puntuales; no es para maquetar columnas.
  • relative conserva su sitio y sirve de referencia para los hijos absolute.
  • absolute se coloca respecto al ancestro posicionado más cercano con top/right/bottom/left o inset.
  • fixed se pega a la ventana; sticky fluye y se pega al llegar a su umbral (necesita top).
  • z-index ordena elementos superpuestos, pero solo dentro de su contexto de apilamiento.
  • transform, opacity < 1 y filter crean contextos de apilamiento nuevos.
  • Un modal = capa fixed + inset: 0 + contenido centrado + z-index alto (y mejor con <dialog>).
  • float queda para que el texto rodee imágenes.

🧠 Comprueba lo aprendido

Elige una respuesta en cada pregunta. Verás al instante si acertaste y por qué.

Un hijo con position: absolute se coloca respecto a…

Busca el ancestro más cercano con position distinto de static; si no hay, usa la página.

¿Qué necesita position: sticky para funcionar?

Sin un umbral (top, bottom…) no sabe cuándo pegarse.

z-index: 9999 no logra poner un elemento encima de otro. ¿Qué es lo más probable?

Los z-index de dentro de un contexto no compiten con los de fuera.

¿Qué diferencia hay entre fixed y sticky?

fixed se coloca respecto a la ventana; sticky conserva su lugar en el flujo hasta que alcanza el umbral.

¿Para qué conviene usar float hoy?

Las columnas se hacen con Flexbox o Grid; float queda para el texto alrededor de imágenes.
