CSS a fondo: del primer estilo al diseño profesional

Aprende a dar aspecto, orden y vida a tus páginas. Entenderás por qué un estilo se aplica y otro no, y construirás layouts modernos que se adaptan a cualquier pantalla.

Antes de empezar
  • Haber hecho el curso de HTML (o saber estructurar una página con etiquetas semánticas).
  • Un editor de código y un navegador moderno.
  • Ganas de probar y equivocarte: los editores en vivo están para eso.

      
Lo que construirás
  • Una tarjeta de producto con sombras y degradados.
  • Layouts reales con Flexbox y Grid.
  • Una galería que se adapta sola a cualquier pantalla.
  • Un tema claro y oscuro con variables.
  • Una **landing page completa** y responsiva como proyecto final.
