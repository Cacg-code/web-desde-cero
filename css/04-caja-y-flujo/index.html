La caja y el flujo del documento

  • ⏱ 40 minutos
  • 📶 Nivel: principiante
  • 🧩 Incluye ejercicio

💡 🎯 Al terminar esta lección podrás…

  • Predecir el tamaño real de una caja y usar box-sizing: border-box.
  • Manejar margin y padding, incluido el colapso de márgenes.
  • Elegir display y entender cómo fluye el contenido.
  • Controlar el desbordamiento y dimensionar con max-width, aspect-ratio y object-fit.

1.Todo es una caja

Para el navegador, cada elemento es una caja rectangular, sin excepción: un párrafo, una imagen, un enlace, incluso un círculo es una caja con las esquinas redondeadas. Entender las cajas es entender el 80% del diseño con CSS.

💡 Consejo · Mira tus cajas

En las herramientas del navegador (F12), al pasar el cursor sobre un elemento se colorean sus capas: azul = contenido, verde = relleno, amarillo = borde, naranja = margen. Es la mejor forma de entender por qué algo está donde está.

2.box-sizing: la propiedad que te ahorra dolores de cabeza

Por defecto, width mide solo el contenido. Si pones width: 300px y padding: 20px y border: 5px, la caja real mide 300 + 40 + 10 = 350 px. Eso complica todos los cálculos.

Con box-sizing: border-box, width incluye el relleno y el borde: la caja mide exactamente 300px.

✏️ Compara content-box y border-box
La primera regla de casi todo proyecto
*, *::before, *::after {
  box-sizing: border-box;
}

Con esa regla, width: 50% significa la mitad del contenedor, incluidos relleno y borde. Es lo que esperas.

3.Margin y padding en detalle

EscrituraSignifica

padding: 8px 16pxArriba y abajo 8px · izquierda y derecha 16px
padding: 8px 16px 4pxArriba 8 · laterales 16 · abajo 4
padding: 1px 2px 3px 4pxArriba, derecha, abajo, izquierda (sentido del reloj)
padding-top, padding-left…Un solo lado
padding-inline, padding-blockLados horizontales / verticales (según el idioma). Igual con margin

Márgenes: tres comportamientos que sorprenden

  1. margin: 0 auto centra horizontalmente un bloque que tenga ancho (width o max-width).
  2. Los márgenes verticales se «colapsan»: dos bloques con margin-bottom: 30px y margin-top: 20px no se separan 50px, sino 30px (se queda el mayor).
  3. Los márgenes pueden ser negativos (margin-left: -10px) para acercar o superponer elementos. Úsalo con cuidado.
✏️ Colapso de márgenes

📌 Nota · ¿Margin o padding?

Una regla práctica: padding para el espacio interior de un componente; margin para separar un componente de otros; y para separar los hijos de un contenedor flex/grid, mejor gap (lo verás en las lecciones 6 y 7).

4.Bordes, esquinas y contornos

Bordes
.caja {
  border: 2px solid #4f46e5;            /* ancho, estilo, color */
  border-bottom: 4px dashed crimson;    /* un solo lado */
  border-radius: 12px;                  /* esquinas redondeadas */
}
.circulo { width: 80px; height: 80px; border-radius: 50%; }
.pildora { border-radius: 999px; }
  • Estilos de borde: solid, dashed, dotted, double, none.
  • border-radius: 50% en una caja cuadrada la convierte en círculo; 999px en una caja larga, en una píldora.
  • outline parece un borde pero no ocupa espacio ni altera el diseño. Por eso lo usa el foco del teclado (outline: 3px solid).
✏️ Formas con border-radius

  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

💡 Consejo · max-width en lugar de width

Un bloque con width: 800px se desborda en un celular. Con max-width: 800px; width: 100%; (o simplemente max-width), se adapta: llega a 800px en pantallas grandes y se encoge en las pequeñas.

8.Errores frecuentes

  • No usar box-sizing: border-box y que los anchos «no cuadren».
  • Esperar que margin: auto centre un bloque sin ancho: no hay nada que centrar.
  • Dar width/height a un elemento inline: se ignora; cámbialo a inline-block o block.
  • Margen vertical que «no suma»: es el colapso de márgenes.
  • Usar height fijo para textos: si el texto crece, se sale. Prefiere min-height.
  • Usar margin para separar elementos dentro de un flex/grid en lugar de gap.
  • Esconder con opacity: 0 algo que no debe ser accesible.

📒 Apuntes para llevar

  • Cada elemento es una caja: contenido, padding, border y margin.
  • box-sizing: border-box hace que width incluya relleno y borde: ponlo en todo el proyecto.
  • padding es interior y tiene el color de fondo; margin es exterior y siempre transparente.
  • Los márgenes verticales se colapsan y margin: 0 auto centra bloques con ancho.
  • border-radius redondea (50% = círculo); outline no ocupa espacio.
  • block, inline, inline-block y none cambian cómo fluye una caja; visibility y opacity ocultan de otras formas.
  • overflow controla lo que no cabe; text-overflow: ellipsis recorta texto con «…».
  • max-width, min-height, aspect-ratio y object-fit hacen cajas flexibles.

🧠 Comprueba lo aprendido

Elige una respuesta en cada pregunta. Verás al instante si acertaste y por qué.

Una caja tiene width: 300px; padding: 20px; border: 5px solid; y box-sizing: content-box. ¿Cuánto mide en total?

300 + 20×2 + 5×2 = 350px. Con border-box mediría 300px.

Dos bloques consecutivos: el primero con margin-bottom: 30px, el segundo con margin-top: 20px. ¿Cuánta separación hay?

Los márgenes verticales se colapsan: se queda el mayor, 30px.

margin: 0 auto no centra mi div. ¿Qué falta casi seguro?

Sin ancho, un bloque ya ocupa todo el espacio: no hay nada que centrar.

¿Qué diferencia a visibility: hidden de display: none?

Con visibility: hidden el hueco permanece; con display: none desaparece del flujo.

¿Qué hace object-fit: cover en una imagen?

cover mantiene la proporción y recorta lo que sobra; contain la muestra completa.
