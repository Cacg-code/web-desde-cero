Ejercicio: Proyecto: landing page responsiva

  • ⏱ 90 minutos
  • 📶 Nivel: principiante

Objetivo

Dar estilo completo a una landing page: cabecera pegajosa, hero con degradado, tarjetas con Grid, galería adaptable, formulario, modo oscuro y animaciones accesibles. El comprobador valida el resultado móvil real y que escribiste las reglas de escritorio.

Este es el HTML de la landing (semántico y accesible). No lo modifiques: tu trabajo es todo el CSS.

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

💡 Pista 1: ¿cómo oculto el enlace para saltar?

.saltar { position: absolute; left: -999px; } y .saltar:focus { left: 8px; top: 8px; }. Así queda fuera de la pantalla hasta recibir el foco con Tab.

💡 Pista 2: el comprobador prueba a 400px

Eso significa que debes ver el diseño móvil: una columna, sin desplazamiento horizontal. Las medidas de escritorio se comprueban leyendo que escribiste las media queries.

🔎 Comprueba tu trabajo

Pega tu código y pulsa Comprobar. La revisión ocurre en tu navegador; nada se envía a ningún sitio. Cada punto en rojo incluye una pista.
