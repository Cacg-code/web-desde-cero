Si pones texto sobre una foto, asegura el contraste: añade una capa oscura (linear-gradient(rgb(0 0 0 / .5), rgb(0 0 0 / .5)) como primer fondo) o una sombra de texto. Una foto bonita con texto ilegible no sirve.

  • La dirección puede ser un ángulo (45deg, 90deg) o una palabra (to right, to bottom right).
  • Puedes poner paradas de color con posición: #4f46e5 0%, #22d3ee 60%.
  • Un degradado es una imagen: va en background o background-image, no en background-color.

3.Sombras y profundidad

box-shadow
/* desplazamiento-x  desplazamiento-y  desenfoque  expansión  color */
.tarjeta { box-shadow: 0 4px 12px rgb(0 0 0 / .12); }

/* Varias sombras: más natural */
.elevada {
  box-shadow:
    0 1px 2px rgb(0 0 0 / .08),
    0 8px 24px rgb(0 0 0 / .12);
}

.hundida { box-shadow: inset 0 2px 6px rgb(0 0 0 / .25); }   /* inset: hacia dentro */
.anillo  { box-shadow: 0 0 0 3px #4f46e5; }                  /* un «borde» que no ocupa espacio */
  • text-shadow hace lo mismo con el texto: text-shadow: 0 1px 3px rgb(0 0 0 / .5).
  • filter: drop-shadow() sigue la forma real de imágenes con transparencia (PNG, SVG), cosa que box-shadow no hace.
  • Las sombras sutiles (poca opacidad, mucho desenfoque) se ven más profesionales que las duras.

📌 Nota · Rendimiento

backdrop-filter y filter: blur() son costosos para el navegador, sobre todo con áreas grandes o animadas. Úsalos con moderación.

⚠️ Importante · opacity afecta a los hijos

Un opacity: .5 en un contenedor hace translúcido también a su texto y a todo lo que contiene. Si solo quieres un fondo translúcido, usa un color con alfa: background: rgb(0 0 0 / .5).

5.Texto con degradado y otros recursos

Texto con degradado
.logo {
  background: linear-gradient(90deg, #4f46e5, #22d3ee);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}
✏️ Texto con degradado

⚠️ Importante · Dar siempre una alternativa

Un texto con color: transparent desaparece si el navegador no entiende background-clip: text. Define antes un color normal y deja transparent para cuando el soporte exista, o envuélvelo en @supports (background-clip: text).

6.Buenas prácticas visuales

  • Menos es más: una o dos sombras y un par de degradados bastan. Cada efecto extra compite con el contenido.
  • Consistencia: usa las mismas sombras y radios en todo el sitio (variables en la lección 11).
  • Contraste primero: comprueba el texto sobre cualquier fondo, también sobre degradados (revisa la zona más clara).
  • Optimiza las imágenes de fondo: usa formatos modernos (WebP, AVIF) y tamaños adecuados.
  • Respeta las preferencias: prefers-contrast y prefers-reduced-transparency existen para quien los necesita.

7.Errores frecuentes

  • Poner un degradado en background-color: no funciona; va en background o background-image.
  • Olvidar background-size y no-repeat y que la imagen se repita o se vea enorme.
  • Texto ilegible sobre una foto.
  • opacity en vez de color con alfa y volver translúcido el texto.
  • Sombras muy oscuras y duras que parecen de los años 2000.
  • Abusar de blur y backdrop-filter y ralentizar la página.
  • Usar box-shadow para imágenes con transparencia (usa drop-shadow).

📒 Apuntes para llevar

  • background admite color, imágenes, degradados y varias capas (la primera queda encima).
  • background-size: cover llena la caja recortando; contain la muestra entera; añade no-repeat y center.
  • linear-gradient, radial-gradient y conic-gradient crean degradados: son imágenes.
  • box-shadow (varias capas, inset, anillos) y text-shadow dan profundidad; las sutiles se ven mejor.
  • opacity afecta a todo el elemento; rgb(… / %) solo al color.
  • filter (blur, grayscale…), backdrop-filter y clip-path aportan efectos, con coste de rendimiento.
  • Sobre fondos con imágenes, asegura siempre el contraste del texto.
  • background-clip: text crea texto con degradado, con alternativa.
