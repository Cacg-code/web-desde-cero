Ejercicio: El stack de hoy: herramientas modernas que verás en los empleos

  • ⏱ 50 minutos
  • 📶 Nivel: intermedio

Objetivo

Reconocer las herramientas modernas más comunes de un proyecto web. Saber qué problema resuelve cada una y cuándo conviene. Crear tu propio plan de aprendizaje de 3 herramientas.

Cómo se trabaja

Es práctica real en tu computadora, con tu propio proyecto. No hay comprobador automático: ve marcando cada paso y verifica el resultado tú mismo. Trabaja en una rama de Git y revisa todo lo que genere la IA.

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

Cómo sé que está bien

  • Tu tabla compara versiones instaladas y últimas disponibles.
  • El archivo en TypeScript compila sin errores.
  • Tu plan tiene un proyecto concreto para cada herramienta.

Pistas

💡 Pista 1: Para probar TypeScript

Con Vite: npm create vite@latest y elige la variante TypeScript; o ejecuta archivos .ts con tu herramienta preferida.

💡 Pista 2: Si hay muchos errores de tipos

Pide a la IA que los explique uno por uno; no los silencies con any.

💡 🏁 Reto extra (opcional)

Configura ESLint y Prettier en uno de tus proyectos y agrega un script npm run revisar.

💡 Entrega

Tabla de versiones, archivo TypeScript y plan de 3 meses.
