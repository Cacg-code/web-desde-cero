Ejercicio: Conectar React con tu API

  • ⏱ 100 minutos
  • 📶 Nivel: intermedio

Objetivo

Llamar a la API desde React con cookies de sesión. Configurar el proxy de Vite y CORS correctamente.

Cómo se trabaja

Es práctica real en tu computadora, con tu propio proyecto. Marca cada paso y verifica el resultado tú mismo. Al final tienes un comprobador que revisa en tu navegador que el código que pegues tenga las piezas clave.

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

Cómo sé que está bien

  • Todas las llamadas a la API salen de src/api.js.
  • El login guarda la cookie y la siguiente petición la envía.
  • Puedes explicar con tus palabras por qué falló el CORS provocado.
  • npm run preview funciona contra tu API.

🔎 Comprueba tu trabajo

Pega tu código y pulsa Comprobar. La revisión ocurre en tu navegador; nada se envía a ningún sitio. Revisa que estén las piezas clave, no que todo funcione: eso lo verificas ejecutando tu proyecto. Cada punto en rojo incluye una pista.

    Pistas

    💡 Pista 1: El proxy no funciona

    Reinicia npm run dev después de editar vite.config.js. Comprueba que la ruta empieza por /api y que la API está corriendo en el puerto del proxy.

    💡 Pista 2: La cookie no aparece

    Mira Network → petición de login → Response Headers: debe haber Set-Cookie. Luego Application → Cookies. Si no está, revisa credentials en ambos lados.

    💡 Pista 3: Quiero provocar un CORS

    Quita tu origen de ORIGENES, reinicia la API y llama desde el front sin proxy (con VITE_API_URL=http://localhost:3000).

    💡 🏁 Reto extra (opcional)

    Sirve el front compilado (dist/) desde la propia Express con express.static y una ruta comodín que devuelva index.html, para tener un solo origen y un solo despliegue.

    💡 Entrega

    Guarda tu práctica en tu carpeta del curso y, si quieres revisión, pásame el archivo o una captura.
