Del curso al trabajo: portafolio y entrevistas

  • ⏱ 90 minutos
  • 📶 Nivel: básico
  • 🧩 Incluye ejercicio

💡 🎯 Al terminar esta lección podrás…

  • Armar un portafolio que demuestre capacidad.
  • Prepararte para pruebas técnicas y conversaciones de trabajo.

Saber programar no basta: hay que demostrarlo. Los reclutadores y clientes miran poco tiempo; dales rápido evidencia.

1.Portafolio

  • 3–5 proyectos de calidad, no 20 mediocres: uno de maquetación impecable, uno con JavaScript puro, uno en React y el full-stack con login y base de datos.
  • Cada uno: captura/GIF, enlace en vivo, enlace al código, qué problema resuelve, tecnologías y qué aprendiste o decidiste.
  • README cuidado, commits ordenados, pruebas y despliegue funcionando.
  • Una página propia rápida, accesible, responsive, con contacto visible.

2.GitHub y LinkedIn

Perfil de GitHub con README, repos fijados, actividad constante. LinkedIn con titular claro ("Desarrollador web front-end/full-stack | React · Node"), proyectos y enlaces. Escribe de lo que aprendes: publicar un pequeño artículo o hilo mensual construye reputación.

3.Entrevistas técnicas

  • Conceptos: cómo funciona la web (HTTP, DNS), el modelo de caja, flexbox/grid, closures, this, promesas/async, el DOM, eventos, ciclo de vida en React, REST, SQL, JWT/cookies, XSS/CSRF.
  • Práctica en vivo: pequeños ejercicios (filtrar un array, maquetar una tarjeta, consumir una API). Habla en voz alta lo que piensas.
  • Proyectos: te preguntarán decisiones ("¿por qué elegiste X?"); conoce bien lo tuyo.
  • Algoritmos: arrays, strings, hash maps, recursión; practica en plataformas como Exercism, Codewars o LeetCode.
  • Inglés técnico: lee documentación y practica explicar tus proyectos.

4.Caminos

Empleo en empresa (junior), freelance (siguiente lección), producto propio, remoto internacional. Lo más importante al inicio: experiencia real acumulada (proyectos para negocios, contribuciones a código abierto, prácticas).

5.Después de este curso

TypeScript en profundidad, Next.js, PostgreSQL avanzado, Docker y despliegues, pruebas end-to-end (Playwright), patrones de diseño, arquitectura. El aprendizaje no termina: lo importante es construir cosas constantemente.
