Proyecto: sistema de citas full-stack

  • ⏱ ≈ 10 horas
  • 📶 Nivel: avanzado
  • 🧩 Incluye ejercicio

💡 🎯 Al terminar esta lección podrás…

  • Unir front en React y API propia en un producto completo y publicado.
  • Trabajar como en un proyecto real: requisitos, pruebas, despliegue y documentación.

Este es tu proyecto final de desarrollo web: el sistema de citas de un negocio (una barbería, un consultorio, un spa) con panel de administración y página pública. Es el tipo de trabajo que puedes vender.

1.Funcionalidades mínimas

  • Página pública del negocio: servicios con precios, horarios, mapa, botón de WhatsApp y formulario para pedir cita (sin cuenta).
  • Panel privado (login): agenda por día/semana, crear/editar/cancelar citas, clientes con historial, servicios y precios.
  • Reglas: sin solapamientos, horarios de atención, duración por servicio, estados de la cita.
  • Reporte: ingresos del mes por servicio y clientes más frecuentes.
  • Avisos: recordatorio por correo o enlace de WhatsApp preescrito.

2.Requisitos técnicos

  • React + Vite + React Router; diseño responsive y accesible (teclado, contraste, etiquetas).
  • API Express con las prácticas de la Parte 2; PostgreSQL o SQLite persistente; migraciones.
  • Pruebas: Vitest en la lógica del front y node:test en la API (≥ 20 en total); CI en GitHub Actions.
  • Seguridad revisada con la lista de b9; sin secretos en el repo; HTTPS y dominio.
  • Rendimiento: Lighthouse ≥ 90 en Rendimiento, Accesibilidad, Buenas prácticas y SEO en la página pública.
  • README con capturas, decisiones técnicas, cómo ejecutarlo y datos de prueba.

3.Cómo trabajarlo (método)

  1. Diseña pantallas en papel/Figma y el diagrama de la base de datos.
  2. Divide en historias pequeñas ("el dueño puede crear una cita") y hazlas una por una, cada una con su commit y, si puedes, su rama + pull request.
  3. Entrega un MVP pronto (login + crear/listar citas) y mejóralo en iteraciones.
  4. Prueba con una persona real y corrige lo que le confunda.

💡 Consejo

Si lo terminas bien, tienes el producto base para ofrecer a negocios (con tu portafolio) y una pieza fuerte para entrevistas.
