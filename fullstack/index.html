Proyecto full stack: une tu front con tu back y llévalo al trabajo

Es el último paso de la ruta. Conectas React con tu API de Express, añades inicio de sesión, CRUD y subida de archivos, y cierras con un sistema de citas completo. Después, portafolio, entrevistas y cómo trabajar con clientes como freelance.

Empezar la lección 1 Ver el temario

Antes de empezar

  • Haber hecho React, Node.js y APIs y Bases de datos.
  • Tener Node.js y un editor como Cursor instalados.

Lo que construirás

  • Un front React conectado a tu API con cookies de sesión.
  • Login, rutas protegidas, CRUD y subida de imágenes.
  • Un sistema de citas publicado, para tu portafolio.

📌 Nota · Precios y plataformas

Los precios y planes que aparecen en este curso son referenciales y cambian. Revisa siempre los sitios oficiales antes de decidir.
