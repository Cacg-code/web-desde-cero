Subir archivos e imágenes

  • ⏱ 70 minutos
  • 📶 Nivel: intermedio
  • 🧩 Incluye ejercicio

💡 🎯 Al terminar esta lección podrás…

  • Recibir archivos en Express con límites y validación.
  • Mostrar las imágenes en el front.

Subir archivos es una de las funciones más peligrosas: un archivo puede ser enorme, falso o malicioso. Reglas: limitar tamaño, validar tipo real, renombrar y no ejecutar jamás.

1.Front: FormData

js
const f = new FormData();
f.append("foto", archivo);                     // archivo viene de <input type="file" accept="image/*">
await fetch("/api/clientes/3/foto", { method: "POST", body: f, credentials: "include" });   // sin Content-Type: el navegador lo pone

2.Back: multer

bash
npm install multer
js
import multer from "multer";
import path from "node:path";
import crypto from "node:crypto";

const PERMITIDOS = { "image/jpeg": ".jpg", "image/png": ".png", "image/webp": ".webp" };

const subir = multer({
  storage: multer.diskStorage({
    destination: "subidas",
    filename: (req, file, cb) => cb(null, crypto.randomUUID() + PERMITIDOS[file.mimetype]),   // nombre nuevo, extensión controlada
  }),
  limits: { fileSize: 2 * 1024 * 1024, files: 1 },                                           // 2 MB
  fileFilter: (req, file, cb) => cb(null, file.mimetype in PERMITIDOS),
});

app.post("/api/clientes/:id/foto", exigirSesion, subir.single("foto"), (req, res) => {
  if (!req.file) return res.status(400).json({ error: "Archivo no válido" });
  db.prepare("UPDATE clientes SET foto = ? WHERE id = ? AND usuario_id = ?").run(req.file.filename, Number(req.params.id), req.usuarioId);
  res.status(201).json({ foto: req.file.filename });
});
app.use("/fotos", express.static("subidas", { dotfiles: "deny", index: false }));

Ojo: el mimetype lo declara el cliente y puede mentir. Para algo serio verifica los primeros bytes del archivo ("firma mágica": JPEG empieza por FF D8 FF, PNG por 89 50 4E 47) o usa una librería de detección, y reprocesa la imagen (por ejemplo con sharp) para descartar contenido oculto.

3.Dónde guardar

  • El disco de muchos hostings es efímero. Para producción usa almacenamiento de objetos: Cloudflare R2, Amazon S3, Supabase Storage. Guardas en la BD solo la clave/URL.
  • Archivos privados (documentos de clientes): URLs firmadas con vencimiento, no carpetas públicas.
  • Optimiza imágenes (WebP/AVIF, varios tamaños) para que el sitio sea rápido.

4.Previsualizar antes de subir

Con URL.createObjectURL muestras la imagen elegida sin enviarla, y validas tamaño y tipo en el front para dar un aviso inmediato (la API vuelve a validar igual).

jsx
function SelectorFoto({ alElegir }) {
  const [vista, setVista] = useState("");
  const [aviso, setAviso] = useState("");

  function cambiar(e) {
    const archivo = e.target.files[0];
    if (!archivo) return;
    if (!["image/jpeg", "image/png", "image/webp"].includes(archivo.type)) return setAviso("Solo JPG, PNG o WebP.");
    if (archivo.size > 2 * 1024 * 1024) return setAviso("Máximo 2 MB.");
    setAviso(""); setVista(URL.createObjectURL(archivo)); alElegir(archivo);
  }
  return (
    <div>
      <input type="file" accept="image/jpeg,image/png,image/webp" onChange={cambiar} />
      {aviso && <p role="alert">{aviso}</p>}
      {vista && <img src={vista} alt="Vista previa de la foto elegida" width="120" />}
    </div>
  );
}

Validar en el front es comodidad; validar en la API es seguridad. Nunca confíes solo en lo primero.

5.Verificar la firma real del archivo

Los primeros bytes de un archivo dicen qué es de verdad, sin importar el nombre ni el mimetype que declare el cliente:

js
import { open } from "node:fs/promises";

const FIRMAS = [
  { tipo: "image/jpeg", bytes: [0xff, 0xd8, 0xff] },
  { tipo: "image/png",  bytes: [0x89, 0x50, 0x4e, 0x47] },
];

async function tipoReal(ruta) {
  const f = await open(ruta);
  const { buffer } = await f.read(Buffer.alloc(4), 0, 4, 0);
  await f.close();
  return FIRMAS.find((x) => x.bytes.every((b, i) => buffer[i] === b))?.tipo ?? null;
}

// en la ruta, tras multer: si (await tipoReal(req.file.path)) no coincide, borra el archivo y responde 400

6.Respuestas de error de multer

Cuando el archivo supera el límite, multer lanza un error con code: "LIMIT_FILE_SIZE". Captúralo en tu manejador de errores y responde 413 con un mensaje claro en vez de un error 500:

js
app.use((err, req, res, next) => {
  if (err.code === "LIMIT_FILE_SIZE") return res.status(413).json({ error: "La imagen supera 2 MB" });
  next(err);
});

7.Servir las imágenes con seguridad

  • Sirve la carpeta con express.static y index: false, para no listar el contenido.
  • Agrega la cabecera X-Content-Type-Options: nosniff (helmet lo hace) para que el navegador no adivine tipos.
  • Nunca guardes archivos subidos dentro de la carpeta del código; usa una carpeta aparte y, mejor aún, almacenamiento de objetos.
  • No uses el nombre original del archivo: puede traer rutas (../../) o caracteres peligrosos.

8.Imágenes pesadas: optimiza

Una foto de celular pesa 4–8 MB. Reduce a un ancho útil (800–1200 px) y convierte a WebP con una librería como sharp antes de guardarla. Tu sitio será más rápido y gastarás menos almacenamiento.

📒 Apuntes para llevar

  • Un archivo puede ser enorme, falso o malicioso: limita tamaño, valida tipo real, renombra.
  • El front usa FormData y no fija Content-Type.
  • El mimetype lo declara el cliente; la firma de los primeros bytes es más fiable.
  • No uses el nombre original ni guardes dentro de la carpeta del código.
  • En producción, usa almacenamiento de objetos (R2, S3, Supabase Storage).

9.Glosario

TérminoSignificado

multerMiddleware de Express que procesa archivos subidos.
mimetypeTipo de contenido que declara el archivo (por ejemplo image/png).

Almacenamiento de objetosServicio para guardar archivos por clave (S3, R2…), independiente del servidor.
