Los cursos

  • Nivel 1 · Empieza aquí

    HTML desde cero

    La estructura de toda página web: texto, enlaces, imágenes, tablas, formularios, accesibilidad, SEO y Git. Termina con tu propia página personal publicada en línea.

    • 11 lecciones + proyecto
    • ≈ 10 horas
    Sin empezar
  • Nivel 2

    CSS a fondo

    Del primer estilo al diseño profesional: selectores, la caja, posicionamiento, Flexbox, Grid, diseño responsivo, animaciones, variables y modo oscuro. Cierra con una landing page.

    • 11 lecciones + proyecto
    • ≈ 12 horas
    Sin empezar
  • Nivel 3

    JavaScript desde cero

    Aprende a programar: variables, decisiones, bucles, funciones, arrays, objetos, el DOM, eventos, asincronía y almacenamiento. Con editor y consola dentro de cada lección. Cierra con una app de tareas.

    • 11 lecciones + proyecto
    • ≈ 14 horas
    Sin empezar
  • Nivel 4

    React desde cero

    Construye aplicaciones con componentes: JSX, props, estado, listas, formularios, efectos, Context, hooks y datos de internet. Con un editor de React en cada lección. Cierra con un carrito de compras.

    • 11 lecciones + proyecto
    • ≈ 16 horas
    Sin empezar
