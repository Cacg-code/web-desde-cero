Listas, claves y renderizado condicional

1.Dibujar listas con map

En casi toda aplicación hay listas: productos, mensajes, tareas, resultados. En React no escribes cada elemento a mano: transformas un array de datos en un array de JSX con map, y React lo dibuja.

⚛️ De datos a elementos
Consola
  1. Tienes datos: un array (de textos, números u objetos).
  2. map recorre cada elemento y devuelve un <li> por cada uno.
  3. React recibe el array de elementos y los dibuja en orden.

Si cambias el array (por ejemplo, con estado) y React vuelve a dibujar, la lista se actualiza sola. No tienes que añadir ni quitar <li> a mano.

3.La prop key: la identidad de cada elemento

Seguramente notaste key={...} en los ejemplos. Es obligatoria en las listas: key le dice a React qué elemento es cuál entre un dibujo y el siguiente, para actualizar solo lo necesario y no mezclar su estado.

Ejecuta este ejemplo y abre la consola: React te avisa si falta la clave.

⚛️ ¿Qué pasa si falta la key?
Consola
Regla de la clavePor qué
Única entre hermanos de la misma listaDos elementos con la misma clave se confunden
Estable: no cambia entre dibujosSi cambia, React cree que es otro elemento y lo reconstruye
Mejor un id de los datosIdentifica al dato aunque cambie de posición
Evita Math.random()Genera una clave nueva en cada dibujo y destruye el estado
Índice solo en listas fijas que nunca se reordenanSi se inserta, borra u ordena, las claves ya no corresponden a los mismos datos

⚠️ Importante · Dónde va la key

La key va en el elemento más externo que devuelve map (el <li> o el componente <Fila />), no dentro. Y no se recibe como prop: React la usa internamente.

4.Mostrar u ocultar: renderizado condicional

Como el JSX es JavaScript, decidir qué mostrar se hace con las herramientas de siempre. Hay tres patrones que usarás todos los días:

PatrónCuándo usarloEjemplo
Ternario ? :Dos opciones: A o B{conectado ? <Panel /> : <Login />}
AND &&Mostrar algo o nada{hayError && <p>Error</p>}
Retorno anticipadoCasos especiales al inicio del componenteif (cargando) return <p>Cargando…</p>;

⚠️ Importante · La trampa del 0

{lista.length && <Lista />} dibuja un 0 cuando la lista está vacía, porque 0 && … vale 0 y React sí muestra los números. Escribe una comparación: {lista.length > 0 && <Lista />}.

5.Filtrar y ordenar antes de dibujar

Lo que map dibuja puede venir de filter o sort. Calcula la lista visible antes del return y deja el JSX simple. Importante: no guardes en estado lo que puedes calcular a partir de otro estado.

6.Errores frecuentes

  • Olvidar la key: React avisa en la consola.
  • Usar el índice como clave en listas que se reordenan o se editan.
  • Poner la key dentro del elemento en lugar de en el elemento que devuelve map.
  • Olvidar el return en map con llaves: lista.map(x => { <li>{x}</li> }) devuelve undefined. Usa paréntesis (…) o escribe return.
  • {n && <X />} con n = 0: dibuja un 0. Compara con n > 0.
  • Mutar el array con sort(): ordena sobre el original. Haz primero una copia: [...lista].sort(…).
  • Guardar en estado la lista filtrada: guarda la lista completa y el criterio; calcula lo visible.

📒 Apuntes para llevar

  • Con lista.map(x => <li key={x.id}>…</li>) conviertes datos en elementos.
  • Toda lista necesita una key única y estable, preferiblemente el id del dato.
  • La key va en el elemento más externo que devuelve map.
  • Renderizado condicional: ternario (a ? b : c), && (algo o nada) y retorno anticipado.
  • Cuidado con {n && …}: si n es 0, se dibuja un 0.
  • Filtra y ordena antes del return; no guardes en estado lo que puedes calcular.
  • Usa [...lista].sort() para no mutar el original.

🧠 Comprueba lo aprendido

Elige una respuesta en cada pregunta. Verás al instante si acertaste y por qué.

¿Para qué sirve la prop key?

Permite a React saber qué elemento es cuál al actualizar la lista.

¿Qué es lo más recomendable como key?

Un id estable identifica al dato aunque cambie de posición.

¿Qué dibuja {items.length && <Lista />} cuando items está vacío?

React muestra los números, y 0 && … vale 0. Usa items.length > 0 && ….

¿Cuál es el patrón adecuado para «A o B»?

El ternario elige entre dos opciones; && muestra algo o nada.

¿Cómo ordenas una lista sin modificar el original?

sort muta el array; copiarlo primero con spread lo evita.
