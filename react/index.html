React desde cero: construye interfaces con componentes

Aprende a crear aplicaciones web que reaccionan a lo que hace la gente: componentes reutilizables, estado, formularios, datos de internet y un proyecto final completo. Cada lección tiene un editor de React que se ejecuta en tu navegador, sin instalar nada.

Antes de empezar
  • Saber **JavaScript** (funciones, arrays, objetos y eventos): haz antes el curso de JavaScript.
  • Conocer HTML y CSS: los cursos de HTML y CSS.
  • Un navegador moderno: el editor de React está dentro de cada lección, sin instalar nada.

      
Lo que construirás
  • Componentes reutilizables con **props**.
  • Interfaces que cambian con **estado** y eventos.
  • Listas, formularios y pantallas que piden **datos de internet**.
  • Estado compartido con **Context** y **useReducer**.
  • Un **carrito de compras** completo como proyecto final.
