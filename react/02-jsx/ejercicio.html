Ejercicio: JSX a fondo

  • ⏱ 20 minutos
  • 📶 Nivel: principiante

Objetivo

Practicar JSX: expresiones entre llaves, un estilo dinámico, atributos propios de JSX y comentarios.

Cómo se trabaja

Escribe un componente llamado App (puedes crear los demás que necesites). Prueba tu código en el editor de abajo; cuando funcione, pega todo el archivo en el comprobador. Los import de react se aceptan y se ignoran, porque aquí React ya está cargado.

⚛️ Tu editor de React (empieza desde aquí)
Consola

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

💡 Pista 1: el estilo

Usa style={{ color: usuario.activo ? "green" : "gray" }} en el <h1>.

💡 Pista 2: varias líneas

Si tu JSX tiene varios elementos, envuélvelos en un <main> o en un fragmento.

🔎 Comprueba tu trabajo

Pega tu código y pulsa Comprobar. La revisión ocurre en tu navegador; nada se envía a ningún sitio. Cada punto en rojo incluye una pista.

    ✅ Ver una solución posible

    Intenta resolverlo antes de mirar. Tu versión puede ser distinta y también correcta.

    App.jsx
    const usuario = { nombre: "Ana Pérez", puntos: 20, activo: true };

export default function App() {
  return (
    <main>
      {/* Cabecera del perfil */}
      <h1 style={{ color: usuario.activo ? "green" : "gray" }}>
        {usuario.nombre}
      </h1>
      <p>Puntos dobles: {usuario.puntos * 2}</p>
      <label htmlFor="correo">Correo</label>
      <input id="correo" type="email" />
    </main>
  );
}

    💡 🏁 Reto extra (opcional)

    Muestra las iniciales del usuario (por ejemplo «AP») usando split(" ") y map, dentro de un <span> con estilo circular.
