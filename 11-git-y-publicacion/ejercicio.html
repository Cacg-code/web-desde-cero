Ejercicio: Git y publicación

  • ⏱ 40 minutos
  • 📶 Nivel: principiante

Objetivo

Convertir tu página en un repositorio Git, subirla a GitHub y publicarla con GitHub Pages. El comprobador revisa la salida de tus comandos.

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

💡 Pista 1: no me deja hacer commit

Si dice «Author identity unknown», falta configurar tu nombre y correo. Si dice «nothing to commit», no hay cambios: edita algo o crea un archivo.

💡 Pista 2: ¿cómo pego tres salidas?

Ejecuta los comandos uno por uno, selecciona el texto de la terminal, cópialo y pégalo en el cuadro del comprobador, uno debajo de otro.

🔎 Comprueba tu trabajo

Pega tu código y pulsa Comprobar. La revisión ocurre en tu navegador; nada se envía a ningún sitio. Cada punto en rojo incluye una pista.

    ✅ Ver un ejemplo de salida correcta

    Intenta resolverlo antes de mirar. Tu versión puede ser distinta y también correcta.

    Ejemplo de lo que debes pegar
    $ git log --oneline
9f2c1ab Agrega formulario de contacto con validación
4be71d0 Mejora el contraste de los enlaces del menú
a3d9f12 Primera versión de mi página personal

$ git remote -v
origin  https://github.com/tu-usuario/mi-pagina.git (fetch)
origin  https://github.com/tu-usuario/mi-pagina.git (push)

$ git status
On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean

    💡 🏁 Reto extra (opcional)

    Crea una rama llamada mejora, cambia el color principal de tu CSS, súbela con git push -u origin mejora y abre un Pull Request en GitHub para unirla a main.
