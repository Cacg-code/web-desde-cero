# Código de conducta

Este proyecto existe para ayudar a la gente a aprender. Para que sea un lugar seguro:

- Trata a todas las personas con respeto, sin importar su nivel de experiencia.
- Las preguntas "básicas" son bienvenidas: todos empezamos de cero.
- Critica el contenido, no a las personas. Sé concreto y amable al señalar errores.
- No se tolera el acoso, la discriminación ni el lenguaje ofensivo.

Para reportar una conducta inapropiada, abre un *issue* privado o escribe a la persona que mantiene el repositorio (perfil de GitHub: Cacg-code). Se revisará con confidencialidad y se podrán eliminar comentarios o bloquear a quien incumpla estas normas.
