Ejercicio: Introducción a CSS

  • ⏱ 40 minutos
  • 📶 Nivel: principiante

Objetivo

Dar estilo a una de tus páginas con un archivo CSS externo: variables, tipografía, menú horizontal, tarjetas, animación y diseño adaptable.

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

💡 Pista 1: mi CSS no se aplica

Revisa que el href del <link> apunte al archivo correcto, que el archivo esté guardado y que recargues con Ctrl + F5. Después busca llaves o puntos y coma que falten.

💡 Pista 2: el menú no queda horizontal

display: flex va en el contenedor de los elementos, es decir, en el <ul>, no en cada <li>.

🔎 Comprueba tu trabajo

Pega tu código y pulsa Comprobar. La revisión ocurre en tu navegador; nada se envía a ningún sitio. Cada punto en rojo incluye una pista.

    ✅ Ver una solución de ejemplo (estilos.css)

    Intenta resolverlo antes de mirar. Tu versión puede ser distinta y también correcta.

    estilos.css
    :root {
  --principal: #4f46e5;
  --fondo: #f7f8fc;
  --texto: #1e2235;
}

* { box-sizing: border-box; }

body {
  margin: 0;
  background: var(--fondo);
  color: var(--texto);
  font-family: system-ui, sans-serif;
  line-height: 1.7;
}

h1, h2 { color: var(--principal); }
a { color: var(--principal); }
a:hover { text-decoration: none; }

nav ul {
  display: flex;
  gap: 16px;
  list-style: none;
  padding: 12px 20px;
  margin: 0;
  background: var(--principal);
}
nav a { color: white; text-decoration: none; font-weight: 600; }

main { max-width: 800px; margin: 0 auto; padding: 20px; }

.tarjeta {
  background: white;
  border: 1px solid #dde2ef;
  border-radius: 12px;
  padding: 16px;
  margin-bottom: 16px;
  transition: transform .2s;
}
.tarjeta:hover { transform: translateY(-3px); }

@media (max-width: 600px) {
  nav ul { flex-direction: column; }
}

    💡 🏁 Reto extra (opcional)

    Añade un modo oscuro: redefine las variables dentro de @media (prefers-color-scheme: dark) { :root { … } } y comprueba cómo cambia toda tu página con solo unas líneas.
