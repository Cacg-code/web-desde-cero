# Curso de HTML desde cero

Curso gratuito en español para aprender HTML paso a paso. Cada lección incluye apuntes, ejemplos de código y un ejercicio práctico.

## Cómo usarlo

- **Online:** abre el sitio publicado en GitHub Pages.
- **En tu computadora:** clona el repositorio y abre `index.html` en el navegador. No necesita instalación.

## Estructura del repositorio

```
index.html            Portada con el temario
assets/               Estilos (estilos.css) y script (curso.js) compartidos
NN-nombre-leccion/     Una carpeta por lección (index.html + ejercicio.html)
```

## Agregar una lección

Copia la carpeta `01-primeros-pasos`, renómbrala y edita el contenido. Luego activa su tarjeta en el `index.html` de la raíz.
