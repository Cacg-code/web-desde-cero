1.Intl: fechas, monedas y listas sin librerías

Intl formatea números, fechas y listas según el idioma. Para precios en soles usa Intl.NumberFormat con currency: "PEN".

2.Arrays: toSorted, toReversed, with y toSpliced

Los métodos clásicos sort() y reverse() modifican el array original. Las versiones nuevas devuelven una copia y dejan el original intacto, clave en React y en cualquier código que evite mutaciones.

⚠️ Nota

Object.groupBy devuelve un objeto sin prototipo. Si necesitas claves que no sean texto, usa Map.groupBy.

📒 Apuntes para llevar

  • Intl.NumberFormat, DateTimeFormat, ListFormat y RelativeTimeFormat formatean según el idioma.
  • toSorted, toReversed, with y toSpliced no mutan el original.
  • Object.groupBy y Map.groupBy agrupan en una sola llamada.
