1.Qué es un array

Un array es una lista ordenada de valores guardados en una sola variable: los nombres de tus contactos, los precios de una tienda, las tareas de un día. Cada valor ocupa una posición (índice) que empieza en 0.

Crear y leer un array
const colores = ["rojo", "verde", "azul"];
//                  [0]     [1]      [2]

console.log(colores[0]);         // "rojo"
console.log(colores[2]);         // "azul"
console.log(colores[5]);         // undefined (no existe)
console.log(colores.length);     // 3
console.log(colores[colores.length - 1]);   // el último: "azul"
console.log(colores.at(-1));     // también el último

⚠️ Importante · Se empieza a contar desde 0

El primer elemento es el [0] y el último es [length - 1]. Es la fuente de errores «por uno» más habitual. Y aunque el array se declare con const, sus elementos sí se pueden cambiar: const impide reasignar la variable, no modificar el contenido.

📌 Nota · Modificar o copiar

Algunos métodos modifican el array original (push, pop, splice, sort, reverse) y otros devuelven uno nuevo (slice, map, filter, concat). Saber cuál es cuál evita sorpresas. Para trabajar con seguridad, prefiere copiar: [...arr] o arr.slice().

4.Los métodos que más usarás: map, filter, reduce

En lugar de escribir un bucle cada vez, los arrays traen métodos que reciben una función (un callback) y hacen el trabajo repetitivo. Los tres más importantes:

MétodoPara quéDevuelveEjemplo
map(fn)Transformar cada elementoUn array del mismo tamaño[1,2,3].map(n => n * 2) → [2,4,6]
filter(fn)Quedarse con los que cumplanUn array igual o más corto[1,2,3,4].filter(n => n % 2 === 0) → [2,4]
reduce(fn, inicial)Resumir todo en un valorUn solo valor[1,2,3].reduce((total, n) => total + n, 0) → 6

💡 Consejo · Cómo leer reduce

reduce((acumulado, elemento) => nuevoAcumulado, valorInicial). En cada vuelta recibes lo acumulado hasta ahora y el elemento actual, y devuelves el nuevo acumulado. El último valor es el resultado final. Si te cuesta, escribe primero el for equivalente y compáralo.

6.Ordenar con sort

sort() ordena modificando el array. Y tiene una trampa famosa: por defecto ordena como texto, no como números.

▶ La trampa de sort
Consola

⚠️ Importante · La función de comparación

(a, b) => a - b devuelve negativo si a va antes, positivo si va después y 0 si empatan. Para textos con tildes y eñes usa a.localeCompare(b, "es"). Y como sort modifica el original, cópialo antes con [...arr] si no quieres perder el orden.

7.Desestructurar y copiar

Sacar valores de un array
const [primero, segundo, ...resto] = [10, 20, 30, 40];
console.log(primero, segundo, resto);       // 10 20 [30, 40]

// Intercambiar dos variables
let a = 1, b = 2;
[a, b] = [b, a];
console.log(a, b);                           // 2 1

// Copiar y combinar
const original = [1, 2, 3];
const copia = [...original];                // copia superficial
const ampliada = [0, ...original, 4];      // [0, 1, 2, 3, 4]

📌 Nota · Copias superficiales

[...arr] y arr.slice() copian un nivel: si los elementos son objetos u otros arrays, la copia comparte esas referencias. Para copias profundas existe structuredClone(arr).

8.Errores frecuentes

  • Empezar a contar desde 1: el primero es el [0].
  • Usar arr[arr.length]: no existe; el último es arr[arr.length - 1].
  • Olvidar el return en el callback de map/filter (con llaves): devuelve undefined.
  • Usar sort() sin función con números.
  • Modificar el array original sin querer con sort, reverse o splice.
  • Usar map solo para recorrer (sin usar el array que devuelve): para eso, forEach o for…of.
  • Usar == o indexOf para buscar objetos: compara referencias, no contenido.
  • Olvidar el valor inicial en reduce: con un array vacío da error.

📒 Apuntes para llevar

  • Un array es una lista ordenada; los índices empiezan en 0 y length da la cantidad.
  • push/pop trabajan al final y unshift/shift al principio; splice quita o inserta en cualquier punto.
  • slice, concat, map, filter y [...arr] no modifican el original; sort, reverse, splice, push… sí.
  • for, for…of y forEach recorren; map transforma, filter selecciona y reduce resume.
  • find, findIndex, some, every e includes buscan y comprueban.
  • sort ordena como texto por defecto: usa (a, b) => a - b para números y localeCompare para textos.
  • La desestructuración (const [a, b] = arr) y el spread ([...arr]) simplifican copias y asignaciones.
  • Una copia con [...arr] es superficial; para copias profundas, structuredClone().

🧠 Comprueba lo aprendido

Elige una respuesta en cada pregunta. Verás al instante si acertaste y por qué.

¿Cuál es el índice del último elemento de un array a?

Como se cuenta desde 0, el último es length - 1 (o a.at(-1)).

¿Qué devuelve [1, 2, 3].map(n => n * 2)?

map devuelve un array nuevo con cada elemento transformado.

¿Qué hace [5, 12, 8].filter(n => n > 6)?

filter se queda con los elementos para los que el callback devuelve verdadero.

¿Qué da [10, 9, 1].sort() sin función de comparación?

Ordena como texto: "1" < "10" < "9". Para números necesitas (a, b) => a - b.

¿Cuál de estos métodos modifica el array original?

push añade al final del mismo array; los otros devuelven uno nuevo.
