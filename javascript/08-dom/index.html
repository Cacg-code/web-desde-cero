El DOM: leer y cambiar la página

  • ⏱ 45 minutos
  • 📶 Nivel: principiante
  • 🧩 Incluye ejercicio

💡 🎯 Al terminar esta lección podrás…

  • Seleccionar elementos con querySelector y querySelectorAll.
  • Cambiar texto, clases, estilos y atributos de forma segura.
  • Crear, añadir y eliminar elementos desde JavaScript.
  • Evitar los errores más comunes con el DOM y el riesgo de innerHTML.

1.Qué es el DOM

Cuando el navegador lee tu HTML, construye un árbol de objetos que representa la página: el DOM (*Document Object Model*). Cada etiqueta es un nodo de ese árbol, y JavaScript puede leerlo y modificarlo; cada cambio se refleja al instante en pantalla.

El HTML y su árbol
<body>
  <h1 id="titulo">Hola</h1>
  <ul>
    <li>Uno</li>
    <li>Dos</li>
  </ul>
</body>

document
└── body
    ├── h1#titulo  →  "Hola"
    └── ul
        ├── li  →  "Uno"
        └── li  →  "Dos"

El objeto document es la puerta de entrada al DOM. Con él buscas elementos, y cada elemento es un objeto con propiedades (textContent, className…) y métodos (append(), remove()…).

📌 Nota · Los editores del curso

En esta lección cada editor tiene una Página (resultado) a la derecha. Tu script modifica esa página. Pulsa Ejecutar para volver a empezar con el HTML original.

⚠️ Importante · null si no existe

Si el selector no encuentra nada, getElementById y querySelector devuelven null, y usar null.textContent da el error *«Cannot read properties of null»*. Casi siempre es una errata en el selector o un script que se ejecuta antes de que el elemento exista (usa defer o pon el script al final).

⚠️ Importante · Seguridad: nunca innerHTML con datos de usuarios

Si insertas con innerHTML un texto que escribió alguien (un comentario, un nombre), esa persona puede colar código malicioso (ataque XSS). Con textContent el texto se muestra siempre como texto, sin riesgo. Regla: usa textContent por defecto, y innerHTML solo con HTML que tú escribiste.

Mantén el aspecto en el CSS y desde JavaScript solo añade o quita clases: tarjeta.classList.toggle("activa"). Así separas las responsabilidades y tu CSS sigue mandando.

5.Crear, añadir y eliminar elementos

  1. Crea el elemento: document.createElement("li").
  2. Dale contenido y atributos: li.textContent = "…".
  3. Añádelo a la página: lista.append(li).

8.Errores frecuentes

  • Script que se ejecuta antes de que exista el elemento: null. Usa defer o ponlo al final del <body>.
  • Errata en el selector: #titulo frente a .titulo frente a titulo.
  • Usar innerHTML con datos de usuario: riesgo de XSS. Usa textContent.
  • Esperar un array de querySelectorAll: es una NodeList (sin map).
  • Cambiar estilos con style en vez de clases: mezclas aspecto y lógica.
  • Escribir elemento.style.font-size: en JavaScript se escribe en camelCase: fontSize.
  • Modificar el DOM dentro de un bucle muy grande: es lento; construye todo y añádelo una vez.
  • Olvidar que createElement no añade nada: hay que append el elemento.

📒 Apuntes para llevar

  • El DOM es el árbol de objetos que representa la página; document es su punto de entrada.
  • Selecciona con getElementById, querySelector (uno) y querySelectorAll (todos), con los mismos selectores de CSS; devuelven null si no encuentran.
  • textContent cambia el texto de forma segura; innerHTML interpreta HTML y solo se usa con datos propios; value lee los campos.
  • classList.add/remove/toggle/contains cambia el aspecto sin mezclar estilos; style, setAttribute y dataset cubren los demás casos.
  • Crea con createElement, añade con append/prepend/before/after y elimina con remove().
  • querySelectorAll devuelve una NodeList: usa Array.from() o [...] para tener map y filter.
  • Ejecuta tu script cuando la página esté lista (defer).
  • Nunca insertes datos de usuarios con innerHTML.

9.Glosario

TérminoSignificado
DOMRepresentación en forma de árbol de objetos de la página.
NodoCada elemento, texto o comentario del árbol.
SelectorTexto (como en CSS) que identifica uno o varios elementos.
textContentPropiedad que lee o cambia el texto de un elemento.
innerHTMLPropiedad que lee o cambia el HTML interno; peligrosa con datos de usuarios.
classListObjeto para añadir, quitar o alternar clases.
NodeListLista de nodos que devuelve querySelectorAll.
XSSAtaque que inyecta código malicioso en una página.
