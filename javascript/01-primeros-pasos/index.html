Primeros pasos con JavaScript

1.Qué es JavaScript

JavaScript es el lenguaje de programación de la web. Mientras HTML da la estructura y CSS el aspecto, JavaScript da el comportamiento: reacciona cuando alguien pulsa un botón, valida un formulario, muestra datos que llegan de internet, guarda información, anima elementos y mucho más.

AspectoHTMLCSSJavaScript
RolEstructura y contenidoAspectoComportamiento
Es…Un lenguaje de marcadoUn lenguaje de estilosUn lenguaje de programación
Ejemplo«Aquí hay un botón»«El botón es azul y redondo»«Al pulsar el botón, se añade un producto al carrito»

Un lenguaje de programación te permite dar instrucciones a la computadora: guardar datos, tomar decisiones, repetir tareas y reaccionar a lo que ocurre. Esa es la diferencia con HTML y CSS, que solo describen.

📌 Nota · JavaScript no es Java

A pesar del nombre, no tienen relación. Se llamó así por una cuestión de marketing en 1995. Hoy JavaScript corre en el navegador, en servidores (con Node.js), en aplicaciones de escritorio y de celular.

Qué vas a poder hacer al final del curso

  • Escribir programas con variables, decisiones, bucles y funciones.
  • Trabajar con listas de datos (arrays) y objetos.
  • Cambiar la página en vivo y reaccionar a clics, teclas y formularios.
  • Pedir datos a internet y guardar información en el navegador.
  • Construir una aplicación de tareas completa.

2.Tu primer programa: la consola

Antes de tocar la página, empecemos por lo más simple: pedirle a JavaScript que escriba un mensaje. Para eso existe console.log(), que muestra cualquier valor en la consola, una herramienta pensada para desarrolladores.

▶ Hola, mundo
Consola

Pulsa Ejecutar y mira la consola de abajo. Cambia los mensajes y vuelve a ejecutar. Equivocarte aquí no cuesta nada.

La consola de tu navegador

Todos los navegadores traen una consola real. Ábrela con F12 y elige la pestaña Consola. Puedes escribir código ahí y ejecutarlo con Enter, y es donde aparecen los errores de cualquier página.

💡 Consejo · Tu laboratorio

Abre la consola de tu navegador y úsala como cuaderno de pruebas: escribe 2 + 2, "hola".toUpperCase() o Math.random() y mira qué responde. Es la mejor manera de explorar el lenguaje.

3.Dónde se escribe JavaScript en una página

FormaEjemploCuándo usarla
Archivo externo<script src="js/app.js" defer></script>Siempre que puedas: ordenado, reutilizable y con caché
Bloque en la página<script> console.log("hola"); </script>Pruebas y ejemplos pequeños (como los de este curso)
Atributo en la etiqueta<button onclick="hacer()">Evítalo: mezcla HTML y lógica y es difícil de mantener
Así se enlaza un archivo JavaScript
<!doctype html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi página</title>
  <script src="js/app.js" defer></script>
</head>
<body>
  <h1 id="titulo">Hola</h1>
</body>
</html>

⚠️ Importante · defer

El navegador lee la página de arriba abajo. Si el script está en el <head> y quiere modificar un elemento del <body>, ese elemento todavía no existe. El atributo defer hace que el script se ejecute cuando la página ya está lista. Úsalo en todos tus scripts externos.

📌 Nota · Los editores del curso

En los editores de las lecciones escribes el código dentro de un bloque <script> junto a tu HTML. Fíjate en que el script está al final del contenido: así los elementos ya existen cuando se ejecuta.

5.Leer los errores: tu mejor maestro

Al programar vas a ver muchos errores. Es completamente normal y todo el mundo los ve, siempre. La consola te dice qué pasó y dónde. Aprender a leerlos es la habilidad más útil de este curso.

MensajeQué significaCausa típica
SyntaxError: Unexpected tokenEscribiste algo que no es JavaScript válidoUn paréntesis, llave o comilla sin cerrar
ReferenceError: x is not definedUsas un nombre que no existeErrata, o usarlo antes de crearlo
TypeError: x is not a functionIntentas «llamar» a algo que no es una funciónNombre mal escrito
TypeError: Cannot read properties of nullPides algo a un valor que no existeUn elemento que no se encontró
▶ Provoca y arregla errores
Consola

Lee el mensaje rojo de la consola. Arréglalo creando la variable (const nombre = "Ana"; antes de usarla) y vuelve a ejecutar.

  1. Lee el mensaje completo, no solo el principio.
  2. Fíjate en la línea que indica.
  3. Busca la errata más probable: nombres, comillas, paréntesis.
  4. Prueba con console.log para ver qué valen las variables.

💡 Consejo · Un error detiene el programa

Cuando JavaScript encuentra un error, deja de ejecutar el resto de ese script. Por eso a veces «no pasa nada»: un error anterior detuvo todo. Mira siempre la consola primero.

6.Tu primera interacción con la página

JavaScript puede leer y cambiar el HTML. Para empezar, una sola idea: buscar un elemento por su id y cambiar su texto.

Cambiar un texto de la página
const saludo = document.getElementById("saludo");   // 1. buscar el elemento
saludo.textContent = "¡Hola desde JavaScript!";      // 2. cambiar su texto
▶ Cambia la página
Consola

Verás cómo cambia el contenido de la Página (resultado). En la lección 8 estudiaremos el DOM a fondo; por ahora basta con que sepas que document representa la página y que con él puedes tocar cualquier elemento.

7.alert, confirm y prompt: pequeños diálogos

JavaScript puede abrir ventanas del navegador para avisar (alert), preguntar sí o no (confirm) y pedir un texto (prompt):

Los tres diálogos clásicos
alert("¡Hola!");                                  // un aviso
const ok = confirm("¿Quieres continuar?");         // true o false
const nombre = prompt("¿Cómo te llamas?");         // el texto, o null si cancela

📌 Nota · En los editores del curso no funcionan

Por seguridad, los editores de este curso bloquean los diálogos (corren en un entorno aislado). Pruébalos en tu propio archivo o en la consola de tu navegador. Y úsalos poco: interrumpen y son poco accesibles; en el curso aprenderás mejores formas de mostrar mensajes dentro de la página.

8.Buenas costumbres desde el primer día

  • Escribe poco y prueba seguido. Ejecuta cada pocas líneas.
  • Nombra las cosas con claridad: precioTotal en vez de x.
  • Usa console.log para investigar: mira qué valen las cosas.
  • Comenta el «por qué», no el «qué».
  • Sangra (indenta) el código para que se lea.
  • Lee la documentación: MDN es tu mejor aliada.
  • Equivocarse es parte del proceso. Nadie escribe programas perfectos a la primera.

9.Errores frecuentes al empezar

  • Olvidar cerrar una comilla, paréntesis o llave.
  • Confundir mayúsculas y minúsculas: getElementById, no getelementbyid.
  • Ejecutar el script antes de que exista el elemento (olvidar defer o ponerlo antes del HTML).
  • Esperar que el código «recuerde» algo que no guardaste en una variable.
  • No mirar la consola cuando algo no funciona.
  • Copiar y pegar sin entender: cambia algo del ejemplo y observa qué pasa.
  • Usar comillas «tipográficas» (“ ”) copiadas de un documento: JavaScript solo entiende las rectas (" ").

📒 Apuntes para llevar

  • JavaScript es un lenguaje de programación que da comportamiento a la página; HTML estructura y CSS da estilo.
  • console.log() muestra valores en la consola (F12); es tu herramienta para explorar y depurar.
  • Enlaza tu código con <script src="…" defer>; defer espera a que la página esté lista.
  • Las instrucciones se ejecutan en orden; terminan en ;; distinguen mayúsculas; los comentarios son // y /* */.
  • Los errores son normales: lee el mensaje, mira la línea y busca la errata. Un error detiene el script.
  • document.getElementById("id") busca un elemento y .textContent cambia su texto.
  • alert, confirm y prompt abren diálogos, pero se usan poco y aquí no funcionan.
  • Escribe poco, prueba seguido y nombra bien las cosas.
