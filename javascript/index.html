Antes de empezar
  • Haber hecho el curso de HTML y, mejor, el de CSS.
  • Un navegador moderno (el editor y la consola están dentro de cada lección).
  • Ninguna experiencia previa programando: empezamos desde la primera variable.

      
Lo que construirás
  • Programas con decisiones, bucles y funciones.
  • Listas de datos que filtras, transformas y ordenas.
  • Páginas que **reaccionan** a clics, teclas y formularios.
  • Datos que llegan de internet y se guardan en el navegador.
  • Una **aplicación de tareas** completa como proyecto final.
