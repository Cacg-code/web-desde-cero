1.Qué es una función

Una función es un bloque de código con nombre que puedes ejecutar cuando quieras, las veces que quieras, y con datos distintos cada vez. Es la herramienta principal para organizar un programa, evitar repetir código y darle nombre a cada tarea.

Ya has usado funciones sin saberlo: console.log(), Math.round() o "hola".toUpperCase() son funciones que escribió otra persona. Ahora escribirás las tuyas.

⚠️ Importante · return frente a console.log

console.log muestra un valor; return lo entrega a quien llamó a la función para que lo use. Una función útil casi siempre devuelve su resultado (y es quien la llama la que decide si lo muestra, lo guarda o lo suma a otra cosa). Si una función no tiene return, devuelve undefined.

Valores por defecto

Un parámetro opcional
function saludar(nombre = "amigo") {
  return `Hola, ${nombre}`;
}
console.log(saludar("Ana"));   // "Hola, Ana"
console.log(saludar());        // "Hola, amigo"

💡 Consejo · ¿Cuál usar?

Para empezar, la declaración (function nombre() {}) es la más legible. Las flechas son perfectas para funciones pequeñas que pasarás a otras (como en map o addEventListener). Con el tiempo verás que cada una tiene su sitio.

4.Ámbito: dónde vive cada variable

El ámbito (*scope*) es la zona del código donde una variable es visible. Las variables creadas dentro de una función no existen fuera de ella:

▶ Ámbito
Consola
ÁmbitoDónde existe
GlobalEn todo el programa (declaradas fuera de funciones y bloques)
De funciónSolo dentro de esa función
De bloqueSolo dentro de { … } si usas let o const (un if, un for…)

💡 Consejo · Evita variables globales

Las variables globales pueden modificarse desde cualquier parte, lo que hace los errores difíciles de rastrear. Pasa los datos por parámetros y devuélvelos con return: tus funciones serán más fáciles de probar y de reutilizar.

5.Funciones puras y pequeñas

Una función pura siempre devuelve lo mismo para los mismos argumentos y no cambia nada fuera de ella. Son las más fáciles de entender, de probar y de reutilizar.

▶ Pura frente a impura
Consola
  • Una función, una tarea: si necesitas «y» para describirla, probablemente son dos funciones.
  • Nombres que son verbos: calcularTotal, esValido, crearTarjeta.
  • Las funciones que devuelven true/false suelen empezar por es, tiene o puede.
  • Pocos parámetros (idealmente 3 o menos).

6.Parámetros rest y spread

Un número variable de argumentos
function sumarTodos(...numeros) {         // ...numeros: agrupa los argumentos en un array
  let total = 0;
  for (const n of numeros) total += n;
  return total;
}
console.log(sumarTodos(1, 2, 3));          // 6
console.log(sumarTodos(10, 20, 30, 40));   // 100

const lista = [4, 8, 15];
console.log(Math.max(...lista));           // ...lista: reparte el array en argumentos

📌 Nota · Los tres puntos

Los ... hacen dos cosas según dónde estén: en la definición de una función agrupan (rest); al llamar o en un array/objeto reparten (spread). Lo volverás a ver en arrays y objetos.

7.Funciones como valores: callbacks

En JavaScript, las funciones son valores: puedes guardarlas en variables, pasarlas como argumentos y devolverlas de otras funciones. Una función que se pasa a otra para que esta la ejecute después se llama callback.

9.Errores frecuentes

  • Olvidar return: la función devuelve undefined.
  • Escribir saludar en vez de saludar(): sin paréntesis no se llama, solo se hace referencia a la función.
  • Usar return y esperar que lo que está después se ejecute: return termina la función.
  • Depender de variables globales en lugar de parámetros.
  • Funciones demasiado largas que hacen muchas cosas.
  • Modificar los argumentos (arrays y objetos) sin querer: se pasan por referencia.
  • Nombres de parámetros iguales a variables de fuera que provocan confusión.
  • Funciones flecha con llaves y sin return: n => { n * 2 } devuelve undefined.

📒 Apuntes para llevar

  • Una función es un bloque con nombre que se define una vez y se llama muchas.
  • Parámetros son los nombres de entrada; argumentos los valores al llamar; return entrega el resultado y termina la función.
  • Tres formas: declaración (function f() {}), expresión (const f = function () {}) y flecha (const f = () => {}).
  • Las variables de una función no existen fuera de ella; las de fuera sí se ven desde dentro.
  • Prefiere funciones puras y pequeñas: reciben datos por parámetros y los devuelven con return.
  • Los valores por defecto (nombre = "amigo") y los parámetros rest (...numeros) dan flexibilidad.
  • Las funciones son valores: se pasan como callbacks, base de eventos y asincronía.
  • Una closure es una función que recuerda las variables del lugar donde nació.

¿Qué devuelve una función que no tiene return?

Sin return, devuelve undefined.

¿Qué diferencia hay entre saludar y saludar()?

Los paréntesis son los que ejecutan la función.

Una variable declarada con const dentro de una función, ¿se puede usar fuera?

Las variables locales no existen fuera de su función.

¿Cuál de estas es una función flecha correcta que devuelve el doble?

Con una sola expresión sin llaves, el resultado se devuelve solo. Con llaves necesitas return.

¿Qué es un callback?

Se ejecuta más tarde, cuando la otra función lo decide.
