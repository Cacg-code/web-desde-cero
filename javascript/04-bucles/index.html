1.Por qué repetir

Muchas tareas consisten en hacer lo mismo varias veces: mostrar los números del 1 al 100, recorrer una lista de productos, sumar todos los precios, buscar un nombre. Escribir cada repetición a mano sería largo, aburrido y propenso a errores. Los bucles le piden a la computadora que repita un bloque de código mientras se cumpla una condición.

2.El bucle for

Anatomía de un for
for (let i = 0; i < 5; i++) {
  console.log("Vuelta", i);
}
//   ① inicio     ② condición   ③ avance
for ( 
let i = 0① inicio
;  
i < 5② condición
;  
i++③ avance
) { … }④ cuerpo
  1. Inicio: se ejecuta una sola vez al principio (let i = 0).
  2. Condición: se evalúa antes de cada vuelta; si es falsa, el bucle termina.
  3. Cuerpo: el código entre llaves se ejecuta.
  4. Avance: se ejecuta al final de cada vuelta (i++). Luego se vuelve a la condición.

3.while y do…while

Repetir mientras se cumpla una condición
let intentos = 0;
while (intentos < 3) {
  console.log("Intento", intentos + 1);
  intentos++;
}

let n = 10;
do {
  console.log("Este se ejecuta una vez aunque n sea 10");
} while (n < 5);

while evalúa la condición primero: si desde el inicio es falsa, no entra nunca. do…while ejecuta primero y evalúa después: entra siempre al menos una vez.

⚠️ Importante · Bucles infinitos

Si la condición nunca se vuelve falsa, el bucle no termina y la página se congela. Siempre asegúrate de que algo dentro del bucle (un contador, una lectura) acabará haciendo falsa la condición. Si pasa en tu navegador, cierra la pestaña. En los editores de este curso, recarga la página.

for…in: las claves de un objeto
const persona = { nombre: "Ana", edad: 30, ciudad: "Lima" };
for (const clave in persona) {
  console.log(clave, "=", persona[clave]);
}

📌 Nota · for…of y for…in no son lo mismo

for…of recorre valores (arrays, textos); for…in recorre claves (objetos). Usar for…in con arrays da los índices como texto y puede incluir propiedades inesperadas: evítalo con arrays.

8.Errores frecuentes

  • Bucle infinito: la condición nunca se vuelve falsa (se olvidó i++).
  • Error «por uno» (off-by-one): usar < cuando debía ser <=, o empezar en 1 en lugar de 0.
  • Modificar la lista que se recorre (añadir o quitar elementos dentro del bucle).
  • Usar var en un for: la variable «se escapa» del bucle. Usa let.
  • Confundir for…of con for…in.
  • Declarar la variable acumuladora dentro del bucle: se reinicia en cada vuelta.
  • Olvidar break y seguir recorriendo cuando ya se encontró lo buscado.

📒 Apuntes para llevar

  • Los bucles repiten un bloque de código mientras se cumpla una condición.
  • for (inicio; condición; avance) es ideal si sabes cuántas vueltas dar; while repite mientras la condición sea verdadera; do…while entra al menos una vez.
  • for…of recorre los valores de un array o texto; for…in recorre las claves de un objeto.
  • break sale del bucle y continue salta a la siguiente vuelta.
  • Un bucle puede contener otro: el interior se repite por cada vuelta del exterior.
  • Cinco patrones: acumular, contar, buscar, máximo/mínimo y construir.
  • Evita los bucles infinitos y los errores «por uno» revisando siempre la condición y el avance.
  • Declara las variables acumuladoras fuera del bucle.

Elige una respuesta en cada pregunta. Verás al instante si acertaste y por qué.

¿Cuántas veces se ejecuta el cuerpo de for (let i = 0; i < 4; i++)?

Con i valiendo 0, 1, 2 y 3: cuatro veces.

¿Qué diferencia hay entre while y do…while?

do…while evalúa la condición después del cuerpo.

Quieres recorrer los valores de un array. ¿Cuál es la mejor opción?

for…of entrega cada elemento directamente.

¿Qué hace continue dentro de un bucle?

continue omite lo que queda de la vuelta actual.

Un bucle while (x < 10) no modifica nunca x dentro del cuerpo. ¿Qué ocurre?

La condición siempre será verdadera y la página se congelará.
