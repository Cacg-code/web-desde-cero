Ejercicio: Variables y tipos de datos

  • ⏱ 30 minutos
  • 📶 Nivel: principiante

Objetivo

Practicar variables, plantillas de texto, operaciones con números y conversión de tipos con un pequeño cálculo de compra.

Antes de empezar

Esta lección no necesita una página: trabaja solo con variables y la consola. Escribe tu código en el editor de abajo y pégalo en el comprobador.

▶ Prueba tu código aquí (opcional)

Pasos

Marca cada paso a medida que lo completes. Tu avance se guarda en este navegador.

💡 Pista 1: ¿cómo escribo la plantilla?

const mensaje = ${cantidad} x ${producto} = $${total.toFixed(2)};. Fíjate en que el símbolo $ antes de ${…} es un signo de dólares normal.

💡 Pista 2: mi `visitas` no es 3

Con let visitas = 0; y luego tres veces visitas++;. Recuerda que const no permite cambiar el valor, así que aquí hay que usar let.

🔎 Comprueba tu trabajo

Pega tu código y pulsa Comprobar. La revisión ocurre en tu navegador; nada se envía a ningún sitio. Cada punto en rojo incluye una pista.
