Variables y tipos de datos

  • ⏱ 40 minutos

  • Manipular texto con plantillas y métodos de string.

1.Variables: cajas con nombre

Una variable es un espacio con nombre donde guardas un valor para usarlo después. Es como una caja con una etiqueta: puedes mirar qué hay dentro, cambiarlo y usarlo cuantas veces quieras.

Crear y usar variables
let edad = 25;                    // la creas con let
const pais = "México";            // la creas con const
console.log(edad, pais);          // 25 "México"

edad = 26;                        // let permite cambiar el valor
console.log("Ahora tengo", edad);
PalabraSe puede reasignarCuándo usarla
constNoPor defecto. Para todo lo que no cambia
letSíCuando el valor tiene que cambiar (un contador, un total)
varSíNo la uses. Es la forma antigua y tiene comportamientos confusos

💡 Consejo · Empieza siempre con const

Usa const y cámbialo a let solo cuando el compilador te lo exija. Así sabes de un vistazo qué valores nunca cambian, y tu código tiene menos sorpresas.

2.Cómo nombrar variables

  • Pueden contener letras, números, _ y $, pero no pueden empezar con número.
  • Distinguen mayúsculas y minúsculas: edad y Edad son variables distintas.
  • No pueden ser palabras reservadas (let, if, class…).
  • Se usa la convención camelCase: precioTotal, nombreDelCliente.
  • Los nombres deben decir qué contienen: total y no t; esMayor y no flag.
  • Las constantes «de verdad» (valores fijos del programa) suelen ir en MAYÚSCULAS: const IVA = 0.16;.

📌 Nota · JavaScript es de tipado dinámico

No declaras el tipo de una variable: JavaScript lo deduce del valor, y una misma variable puede cambiar de tipo con el tiempo. Es flexible, pero obliga a ser cuidadoso: muchos errores vienen de tipos que no son los que creías.

4.Trabajar con texto

Strings: lo esencial
const nombre = "Ana";
const apellido = 'Pérez';

console.log(nombre + " " + apellido);        // unir con +
console.log(`Hola, ${nombre} ${apellido}`);  // plantilla de texto (¡mejor!)
console.log(nombre.length);                  // 3  (cantidad de caracteres)
console.log(nombre[0]);                      // "A" (primer carácter)

Las plantillas de texto (comillas invertidas ` `) permiten **insertar valores** con ${…}` y escribir varias líneas. Son la forma más cómoda de componer mensajes.

⚠️ Importante · Los strings no se modifican

Los métodos de texto devuelven un texto nuevo, no cambian el original. frase.toUpperCase(); por sí solo no hace nada visible: debes guardar o usar el resultado (const grande = frase.toUpperCase();).

📌 Nota · ¿Por qué 0.1 + 0.2 no da 0.3?

Las computadoras guardan los decimales en binario y algunos no se pueden representar con exactitud. No es un error de JavaScript: pasa en casi todos los lenguajes. Para dinero, redondea con toFixed() o trabaja en centavos (números enteros).

Cuando recibes datos de un formulario o de internet, casi siempre son texto, aunque parezcan números. Hay que convertirlos:

⚠️ Importante · El operador + con texto

Si uno de los lados de + es texto, JavaScript concatena en vez de sumar: "5" + 3 da "53". Convierte antes con Number(). Con -, * y / sí convierte solo, pero conviene ser explícito.

🔍 Ejemplo · Los valores «falsos»

Se comportan como false al convertirlos a booleano: false, 0, "" (texto vacío), null, undefined y NaN. Todo lo demás es «verdadero», incluso "0" y []. Lo usarás en la próxima lección para tomar decisiones.

7.Errores frecuentes

  • Reasignar una const: TypeError: Assignment to constant variable.
  • Usar una variable antes de crearla: ReferenceError o undefined.
  • Sumar textos creyendo que son números: "5" + 3 → "53".
  • Olvidar convertir lo que viene de un formulario.
  • Confundir null y undefined: undefined es «aún no tiene valor»; null es «vacío a propósito».
  • Esperar que toUpperCase() modifique el original.
  • Comparar números decimales con === tras operar (0.1 + 0.2 === 0.3 es false).
  • Nombres poco claros que obligan a adivinar qué guarda cada variable.

📒 Apuntes para llevar

  • Una variable guarda un valor con nombre. Usa const por defecto, let si debe cambiar y nunca var.
  • Los nombres van en camelCase, no empiezan con número ni usan palabras reservadas, y deben decir qué guardan.
  • Tipos: string, number, boolean, undefined, null, bigint, symbol y object. typeof consulta el tipo.
  • Las plantillas de texto ` Hola ${nombre} ` insertan valores y son la mejor forma de componer mensajes.
  • Los métodos de texto (toUpperCase, includes, slice, split, trim…) devuelven valores nuevos.
  • Math.round/floor/ceil/random y toFixed() ayudan con los números; cuidado con los decimales.
  • Number(), parseInt(), parseFloat(), String() y Boolean() convierten tipos.
  • "5" + 3 concatena: convierte siempre los datos de un formulario antes de operar.
