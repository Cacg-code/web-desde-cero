1.Qué es un objeto

Un objeto agrupa datos relacionados bajo nombres (propiedades). Mientras un array es una lista ordenada por posición ([0], [1]…), un objeto es un conjunto de pares nombre–valor: describe una cosa con todas sus características.

Un objeto que describe a una persona
const persona = {
  nombre: "Ana",
  edad: 28,
  activa: true,
  hobbies: ["leer", "correr"],
  direccion: { ciudad: "Lima", pais: "Perú" }
};

console.log(persona.nombre);              // notación de punto: "Ana"
console.log(persona["edad"]);             // notación de corchetes: 28
console.log(persona.direccion.ciudad);    // objetos dentro de objetos: "Lima"
console.log(persona.hobbies[0]);          // "leer"

💡 Consejo · Combina ?. y ??

?. devuelve undefined si algo en la cadena falta, y ?? aporta un valor por defecto solo para null/undefined. Son muy útiles con datos que llegan de internet, donde nunca sabes qué campos faltan.

6.JSON: el formato de intercambio

JSON (*JavaScript Object Notation*) es un formato de texto para intercambiar datos entre programas. Se parece a un objeto de JavaScript, con reglas más estrictas: las claves y los textos van entre comillas dobles y no admite funciones ni undefined.

FunciónHaceEjemplo
JSON.stringify(valor)Convierte un valor a texto JSONJSON.stringify({a: 1}) → '{"a":1}'
JSON.parse(texto)Convierte texto JSON en un valorJSON.parse('{"a":1}') → {a: 1}

📌 Nota · Para qué sirve

JSON es el formato en que casi todas las APIs devuelven datos y en que se guardan cosas en localStorage (lecciones 10 y 11). Un error de sintaxis en el texto hace que JSON.parse lance una excepción, así que se suele envolver en try…catch.

9.Errores frecuentes

  • Confundir . con []: obj.clave busca la propiedad literal «clave»; obj[clave] usa el valor de la variable.
  • Pensar que const hace el objeto inmutable: solo impide reasignar la variable; puedes cambiar sus propiedades (Object.freeze lo impide).
  • Copiar con = esperando una copia: const b = a; apunta al mismo objeto. Usa { ...a } o structuredClone(a).
  • Usar una flecha como método y perder this.
  • Leer una propiedad de undefined: usa ?. o comprueba antes.
  • Comparar objetos con ===: dos objetos distintos con el mismo contenido no son iguales.
  • JSON con comillas simples o con una coma final: no es válido.
  • Olvidar la coma entre propiedades.

📒 Apuntes para llevar

  • Un objeto agrupa datos relacionados en pares clave: valor; se accede con obj.clave o obj["clave"].
  • Una propiedad que es una función es un método; this apunta al objeto. Usa la sintaxis normal, no flechas, para métodos.
  • Atajos: propiedades abreviadas { nombre }, desestructuración const { a, b } = obj y spread { ...obj, a: 1 }.
  • Object.keys/values/entries convierten un objeto en arrays para recorrerlo.
  • ?. evita errores con valores que faltan y ?? aporta valores por defecto.
  • JSON.stringify y JSON.parse convierten entre objetos y texto; structuredClone hace copias profundas.
  • Las listas de objetos son el formato más habitual de datos; los métodos de array funcionan igual.
  • Los objetos se copian y comparan por referencia, no por contenido.
